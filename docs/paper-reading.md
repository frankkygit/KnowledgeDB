# 论文展示与内容检索规范

日期：2026-10-20。状态：待实施。页面参考 [chengwei 的知识库](https://chengwei920412.github.io/index.html)，默认先读概述，通过链接进入全文翻译；延续 GitHub Pages 公开程序、私库授权读取的数据方案。

## 1. 左侧列表，右侧内容

桌面采用两栏阅读布局：左侧固定宽度的可滚动列表，右侧为正文阅读区。左侧顶部提供全库内容搜索，下面是论文、笔记、专题；论文可按主题或年份折叠，显示标题、年份和处理状态。点击论文默认打开概述，选中项清楚标识；右侧独立滚动时左侧列表保持可用。

右侧顶部显示论文标题、作者、年份/会议（可确认时）、来源版本与标签，并提供“原论文”“中文翻译”“我的笔记”入口。正文按章节展示技术概述，可提供“本页目录”折叠入口；不强制常驻第三栏。文章下方是当前文档讨论与待重新链接列表。

手机端将左侧收起为抽屉，通过菜单按钮打开；搜索入口和返回概述入口始终可用。切换论文或从搜索跳转后关闭抽屉，不要求同时挤下两栏。

## 2. 默认概述内容

检查的 [NavGPT-3 参考论文页](https://chengwei920412.github.io/paper_reading/2610.10787_NavGPT-3_Harnessing_Context_in_a_Hierarchical_Navigation_Runtime/technical_report.html) 包含概览、研究动机、方法、实验、见解、局限、相关方法对比和附录。借鉴其组织方式，为每篇论文生成有章节的技术概述，不能只复制摘要，也不机械补齐论文没有报告的信息。

| 模块 | 应表达的内容 |
| --- | --- |
| 基本信息与一句话总结 | 原文来源、作者/年份、研究任务、解决问题的核心思路 |
| 核心贡献 | 相对已有方法改变了什么，指出论文中的依据 |
| 背景与动机 | 问题定义、现有方法不足、适用条件 |
| 方法与流程 | 整体架构、关键模块、输入输出、训练/推理流程，必要的公式或图示 |
| 实验与结果 | 数据集、指标、基线、主要结果与消融；数字注明表/图/章节出处 |
| 局限与对比 | 作者承认的限制、实验覆盖边界，与相关方法的差异 |
| 阅读见解与工程启示 | 明确标为 Agent 分析或待验证推断，不能冒充作者结论或用户判断 |
| 待核对事项与资源 | 解析不清之处、术语、论文/代码链接、相关条目 |

用户自己的理解与实验仍写 notes.md。概述可以链接这些笔记，但 Agent 不自动编造“我的评价”。生成模板见 [论文概述模板](../templates/paper-overview.md)。

## 3. 文档角色与翻译入口

| 文件 | 职责 | 页面行为 |
| --- | --- | --- |
| index.md | 论文元信息、原文资源、文档入口映射 | 条目导航；不再复制一份概述正文 |
| analysis.md | 默认论文概述/技术解读 | 点击左侧论文后加载的主内容 |
| translation.md | 完整中文翻译，保留原文章节、公式和图表编号 | 通过“中文翻译”链接加载并渲染 |
| notes.md | 用户理解、疑问与验证记录 | 通过“我的笔记”进入；不存在时显示尚无笔记 |

每份文档有独立 documentId。catalog 记录 paperId、entryDocumentId、overviewDocumentId、translationDocumentId、notesDocumentId；overviewDocumentId 默认指向 analysis.md，缺失的可选文档字段为 null。条目首次进入优先显示 overviewDocumentId；概述未生成时显示“概述待生成”与已有资源，不无提示切到全文翻译。

“中文翻译”是应用内链接，不直接跳到 GitHub raw URL，也不默认显示 Markdown 源码或触发下载。阅读器按固定 docsCommit 和 translationDocumentId 从私库读取对应 Markdown，在右侧渲染，保留左侧选中论文、公式/图片显示、段落按钮与评论。顶部提供“返回论文概述”。另有需要时可加“查看 Markdown 源文”或下载，但不是主入口。

翻译不存在时入口显示“尚未生成”；只有部分翻译时显示“部分翻译”，明确已完成章节；解析失败时提示重试。返回概述恢复原滚动位置；浏览器前进/后退可恢复当前文档。文档链接按固定 ID 解析，不绑定目录名或文件名。

GitHub Pages 第一版采用 hash 阅读路由，例如 `#/paper/<paperId>` 打开默认概述、`#/document/<documentId>` 打开翻译/笔记，段落位置放在 hash 内参数中。刷新仍先加载站点入口；授权后恢复目标，不依赖服务器配置文章路径回退。通用路由代码公开，私人条目列表和标题从私库加载。

## 4. 内容检索

第一版是全文检索，不只过滤左侧标题。默认检索论文概述、中文翻译、个人笔记、资料笔记与专题正文；可筛选内容类型与当前论文。评论全文搜索暂不作为第一版必做项，评论仍可在文档讨论区读取。

搜索框位于左侧顶部，并提供顶栏/手机搜索按钮和 Ctrl/Cmd+K 快捷入口。输入中文、英文、术语、论文名或正文片段均可检索；中文不要求用户人为插入空格，英文大小写归一。标题/章节/术语命中优先，正文命中仍返回；空输入显示提示，不发起全库逐文件请求。

结果显示论文或笔记标题、内容类型、命中章节、文本片段和高亮词。点击结果在右侧打开实际命中的概述、翻译或笔记，并滚动到命中段落；不能把所有论文命中统一带回概述首页。没有有效 blockId 时定位章节，并提示位置已变化。

检索索引放私有 docs 库 catalog/，按文档/分片读取，在已授权浏览器内搜索。入库时生成，正文更新时同步，记录 docsCommit/contentRevision、documentId、paperId、内容类型、章节和可用 blockId。索引与正文版本不一致时重新读取或提示更新，不用旧偏移静默定位。检索高亮与评论高亮独立，不把搜索命中创建为评论绑定。

加载中、未授权、无结果、索引缺失、读取失败分别给出状态；索引缺失时可继续阅读已知文档并提示重新生成索引，不能把“未加载索引”说成“没有相关内容”。私人标题、结果片段、正文和索引不进入公开 Pages 产物或持久浏览器缓存。

## 5. 评论连续性

概述和翻译都支持段落评论；通过各自 documentId 区分，paperId 只负责把页面组织在同一篇论文下。概述页底默认只列概述的讨论，翻译页底只列翻译讨论，切换文档不自动转移关联。可在入口旁显示其他文档的待链接数量，但不能混成当前正文的高亮。

重写概述、重译全文、检索索引重建均不删除评论。原位置不可信时仍按已有约定进入当前文档页底待链接区，供用户确认新目标。所有步骤继续使用 comments 库的日期分片与稳定 threadId。

## 6. 验收

- 点击左侧论文，右侧默认显示概述；章节涵盖问题、方法、结果和局限，来源与推断分明。
- 点击中文翻译，右侧渲染实际 translation.md，公式/图片可读；保持论文选中状态，可返回概述。
- 概述与翻译的评论分别归属；重译后旧评论在翻译页底仍可找回。
- 用仅在翻译正文、仅在笔记正文出现的中英文词检索，结果均能打开实际文档和命中位置。
- 页面深链接、刷新、前进/后退和手机抽屉可用；刷新需重新授权时，授权后恢复目标。
- 未授权与索引加载失败不能显示为“无搜索结果”；退出后清理当前私人检索状态。

本文件定义待实现行为，不代表已建成阅读网站或复刻参考站样式。
