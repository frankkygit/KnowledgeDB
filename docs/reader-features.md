# 阅读定位、评论与 HTML 缓存

当前实现（2026-10-20）：

- 正文上方的“本页目录”列出一至六级标题。选择标题后关闭目录并滚动到目标；文内原始锚点链接仍可跳转。标题定位 ID 与评论段落 ID 相互独立。
- 工具栏和右下角都有“返回文首”，定位当前文档正文开头。
- 普通正文段落内选词出现“引用并评论”；点击段落出现“评论此段”。仅有稳定入库标记的顶层普通段落可评论；列表、表格、代码等不生成临时身份。跨段、跨公式选词不开放。
- 评论区可单独连接已初始化的私有 comments 仓库及分支。令牌仅授予该库 Contents 读写权限，在网页填写，只保留标签页内存。正文库继续只读。当前使用的评论私库为 `frankkygit/KnowledgeDB-comments`，在评论连接框填写；不自动创建远程仓库或代用户生成令牌。
- 已实现创建讨论与首评、读取所有日期分片后按文档展示、每次显示二十组及继续加载、刷新评论、当前版本跳转段落。正文版本不同的讨论保留原引用并显示“待重新链接”。回复、编辑和人工重新链接界面及引用高亮仍待实现，不能把它们视为已交付。
- 保存前从固定 docs commit 读取版本快照，核对文档、版本、段落纯文本和 Unicode 码点范围。按上海日期选择分片，以 comments HEAD 为父提交创建 Git 对象，非强制更新分支；并发最多重试三次，同 requestId 去重。读取遇到不完整修订链、未知操作或异常分片布局时停止，避免覆盖损坏数据。
- 网络失败或权限不足保留当前草稿与请求 ID；在确认上次保存结果前重试须保留原内容。草稿不写持久存储，刷新或断开后不会保留。本地草稿预览可以体验选词与输入，不提交正式评论。

HTML 缓存遵循本次用户明确要求，作为早期“私人内容仅留会话内存”规则的有限调整：

- 只有经授权读取并清理过的派生 HTML 存入浏览器 IndexedDB，最多保留三十份。令牌、评论、原始 Markdown、索引、图片字节和 Blob URL 不写此缓存；缓存绝不复制到 Pages 产物。
- 键包含渲染器版本、仓库、固定 docs commit、文档 ID、路径及正文版本。命中时直接加载 HTML 并再次安全清理，跳过 Markdown 和公式渲染；版本变化时重新生成。
- 刷新后 HTML 可复用，但须先重新授权读取私库目录与搜索索引；缓存不是离线入口。图片仍通过授权请求获取。
- “清除 HTML 缓存”和主动“断开连接”清除持久缓存。刷新/关闭页面仅清理会话和令牌，保留 HTML 以供下次授权后复用。浏览器禁用存储或配额不足时退回内存缓存，不阻塞阅读。本地未发布草稿不写此持久缓存。

验证：`npm run check` 包含 Markdown 与阅读器回归；`npm run build`、`npm run check:public` 检查公开产物。Git 写入并发与幂等使用模拟 GitHub 验证；用户已在浏览器成功创建真实私库测试评论，随后按要求通过撤销提交从当前分支移除。真实多客户端并发与回复等后续功能仍需单独验收。线上发布状态以 GitHub Pages 部署记录为准。
