# 知识库生成技能

存放用于论文入库、翻译解读、资料整理和已有内容更新的技能。这里是项目内受版本控制的技能库，不代表已安装到当前 Agent 的自动发现目录；使用时明确提供对应 `SKILL.md` 路径。后续需要自动发现时再按具体 Agent 的安装机制配置，不移动原始维护副本。

| 路径 | 用途 | 状态 |
| --- | --- | --- |
| `local/kb-paper-ingest/SKILL.md` | PDF 元信息、默认概述、翻译入口与全文索引 | 已创建；应用和校验脚本待实施 |
| `local/kb-note-ingest/SKILL.md` | 网页资料与个人总结入库 | 已创建；应用和校验脚本待实施 |
| `local/kb-content-update/SKILL.md` | 重译、重整与评论影响报告 | 已创建；应用和校验脚本待实施 |
| `third-party/` | 第三方解析、翻译等技能 | 尚未导入 |

论文展示遵循 [论文阅读规范](../docs/paper-reading.md)，默认打开概述，翻译用稳定文档链接渲染；生成模板为 [paper-overview.md](../templates/paper-overview.md)。

正文生成和更新写入 `sources/docs` 指定的私有子库，包含正文、快照和 catalog 索引；技能不代替浏览器获取令牌，不向公开 Pages 产物写私人内容。详细边界见 [浏览器直连 GitHub](../docs/browser-github-access.md)。

`registry.json` 记录技能名称、路径、类型、版本、来源、许可证和用途。自建技能与内容一起审阅和更新；不将 Skill 内容发布到阅读网站。

第三方接入规则：

支持“导入仓库”和“本机外部安装”两种方式。以下保留目录与注册路径的要求适用于导入仓库的技能。本机外部安装的技能不复制到 `third-party/`，不在 `registry.json` 中伪造仓库内路径；在项目 README 记录来源、许可证、固定 commit、机器路径、依赖、安装/验证状态及更新方式，调用限制写入 AGENTS.md。仍需审阅配套脚本和依赖，安装后试跑；未经验证不得标记为可用。当前 `nature-academic-search` 采用本机外部安装方案，详见 [安装说明](../README.md#本机学术检索技能)。

1. 每个技能独立目录，保留原始 SKILL.md、许可证及必要支持文件。
2. 登记来源 URL、固定版本或 commit、许可证及本地修改说明；确认允许的存储与使用方式，不把未知许可证默认当成许可。
3. 第三方不直接覆盖自建技能；需要适配时增加本地包装技能，优先保持原包可追踪。
4. 导入或更新时审阅脚本、依赖、外部上传、凭据与写入范围，使用一份本地样稿试跑。技能指令不能扩大用户授权。
5. 更新固定到明确版本，检查输出差异、文档/段落 ID 保留和评论影响，再替换注册记录。不自动拉取浮动最新版。

推荐调用示例：读取 `skills/local/kb-paper-ingest/SKILL.md`，将指定 PDF 生成为论文翻译与解读草稿；仅修改本地仓库，返回来源、待核对项和评论影响，不自动发布。
